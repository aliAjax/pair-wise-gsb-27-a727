# 物流费用试算 · 运输委托滞留费责任确认与减免台

- 行业：物流
- 技术栈：Vue3、Vite、TypeScript、Pinia、Element Plus
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

## 功能闭环

1. **费用试算（报价）**：登记客户、线路、重量、已确认运费与服务类型，报价在「草稿 → 已报价 → 已复制」间流转。
2. **运输委托**：只有「已报价」记录能生成委托，一条报价只能生成一次；登记等待起止、责任方（系统/客户）与费用上限。
3. **滞留费规则（按线路）**：免费等待时段内不计费；超出部分按整点向上取整 × 超时单价计算，并按登记的路线上限裁剪，超限部分不得确认。
4. **责任确认与凭据**：系统责任须附「线路公告」编号，客户责任须附「签收记录」编号；凭据缺失时只能「留待复核」，补齐凭据后可复核通过。
5. **减免**：非系统（客户）责任累计减免不得超过已确认运费的 20%；系统责任可全额减免。超额度整笔拒绝，并展示委托编号、责任方、申请原值、上限与命中规则。
6. **结算与补录**：已确认版本结算后费用冻结；补录只能新建带原因的版本，旧版本、旧值与减免记录只读保留。
7. **持久化**：委托、凭据、减免、版本与线路规则均保存在浏览器 localStorage，刷新后一致。

## 分层结构（规则 / 存储 / 页面分离，无新增依赖）

- `src/logistics/types.ts`：领域类型
- `src/logistics/rules.ts`：滞留费试算、凭据要求、减免额度等纯规则
- `src/logistics/storage.ts`：localStorage 读写
- `src/stores/logistics.ts`：Pinia 状态与业务动作
- `src/pages/`、`src/components/`：报价页、滞留费确认台与委托卡片
