# 运输委托滞留费责任确认与减免台

由物流费用试算器扩展而来，保留报价试算能力，新增滞留费责任确认与减免闭环。

- 行业：物流
- 技术栈：Vue3、Vite、TypeScript、Pinia、Element Plus（未新增依赖）
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

## 业务规则

- 只有「已报价」记录才能生成运输委托；委托登记线路、等待起止、责任方和费用上限。
- 滞留费 = max(0, 等待小时 − 免费时段) × 线路小时费率；超过线路上限的部分不得确认。
- 系统原因须附「线路公告」，客户原因须附「签收记录」，凭据缺失时留待复核。
- 非系统责任减免不得超过已确认运费的两成；系统责任可全额减免（不超过已确认滞留费）；超额度整笔拒绝并展示委托、责任方、原值、上限和规则。
- 结算后费用冻结；补录只能新建带原因版本，旧值冻结保留。
- 数据保存在浏览器 localStorage，刷新后委托、凭据、减免和版本一致。

## 目录结构

- `src/detention/rules.ts` —— 滞留规则（纯函数：计费、凭据、减免）
- `src/detention/storage.ts` —— 存储层（localStorage 持久化、状态流转、版本快照）
- `src/pages/` —— 页面层（报价试算、线路登记、滞留费责任台）
